## What is this?
This is a library that is used and updated along side Gadgets & Gizmos [Modrinth](https://modrinth.com/mod/create-aeronautics-gadgets-and-gizmos) [Curseforge](https://www.curseforge.com/minecraft/mc-mods/create-aeronautics-gadgets-and-gizmos) and any future mods I make.
It does nothing on its own.

## Run gradlew clean build to compile the library binary
The library is opensource under MIT licensing while Gadgets & Gizmos remains ARR.
